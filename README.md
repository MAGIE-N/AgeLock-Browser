# AgeLock-Browser
A tamper-resistant browser enforcing age-appropriate access through TPM 2.0/Secure Enclave-bound, non-resettable age credentials (5-12, 13-20, 20+). It filters content on-device using DistilBERT with SHAP explanations and NSFW.js, plus a 100+ site whitelist for ages 5-8. It stores no history or telemetry, and is tested against commercial filters.
